# Бэклог домена system

Задачи, которые решено сделать, но еще не начаты. Порядок — по важности.

## 1. Куда уходит место на `C:` у ЧЕБОКСАРЫ_143 (05.10.2026)

На `C:` (SSD 128 ГБ) осталось 7,9 ГБ (7,1%), за 05.10 — минус ~4 ГБ. При таком темпе диск заполнится за 2 дня, и
начнут падать сбор отчетов (копия профиля Edge) и обновления Windows. Разобрать по SSH (`ssh pvz143`), что растет:
`%TEMP%` пользователей, `C:\Windows\Temp`, `C:\Windows\SoftwareDistribution`, копии профиля Edge парсера
(`%LOCALAPPDATA%\scheduler\EdgeParserSnapshot` у «Оператора»), кэш Edge, логи scheduler, `Windows.old`, точки
восстановления, файл гибернации. Результат — список того, что безопасно удалять, и почему растет.

## 2. Задача очистки диска от мусора (`DiskCleanupScript`)

По итогам п. 1 — регулярная задача в `tasks/system` (как `UpdaterScript`, `HealthMonitorScript`): удаление
временных файлов и устаревших копий профиля Edge, старых логов scheduler, кэша обновлений Windows; только
безопасные пути, с отчетом в лог об освобожденном месте. Связать с мониторингом: тревога `LOW_SPACE_C`
(HEALTH_MONITOR_PLAN.md, раздел 4) — повод проверить, что очистка работает.

## 3. «Наивысшие права» для `\Задачи system` на всех ПВЗ

Нужно HealthMonitorScript для SMART (HEALTH_MONITOR_PLAN.md, раздел 8). Планировщик → свойства задачи → «Выполнить с
наивысшими правами» → пароль `aniki`. Сделать на 144, 143, 182, 340 и в эталонном образе (docs/imaging).
