# Метод `set_pvz()`

## Версия
**0.0.2**

## Описание
Метод `set_pvz()` устанавливает нужный ПВЗ (пункт выдачи заказов) в выпадающем списке на странице Ozon. Метод используется для обеспечения правильной локации при сборе данных из системы Ozon.

## Сигнатура
```python
def set_pvz(self, target_pvz: str) -> bool
```

## Параметры
- **target_pvz** (`str`): Целевой ПВЗ для установки в выпадающем списке

## Возвращаемое значение
- **bool**: True, если ПВЗ успешно установлен

## Используемые параметры конфигурации
- **selectors.pvz_selectors.dropdown_candidates** (`list[str]`): Селекторы поля выбора ПВЗ (fallback: `dropdown`)
- **selectors.pvz_selectors.option_candidates** (`list[str]`): Шаблоны селекторов опции с плейсхолдером `{target_pvz}` (fallback: `option`)

## Разметка списка ПВЗ (Турбо ПВЗ 3.11.x)
```text
div.ozi__dropdown__dropdown__<hash>              ← контейнер списка (вне #ozi-window-teleport-target)
  div.ozi__dropdown-item__dropdownItem__<hash>   ← пункт списка
    div.ozi__data-content__dataContent__<hash>
      div.ozi__data-content__label__<hash>       ← «ЧЕБОКСАРЫ_144»
      div.ozi__data-content__caption__<hash>     ← адрес
```

Первый селектор в `option_candidates` соответствует этой разметке:
```text
//div[contains(@class, 'ozi__dropdown-item__dropdownItem__')]//*[contains(@class, 'ozi__data-content__label__') and normalize-space()='{target_pvz}']
```

## Пример использования
```python
success = parser.set_pvz("ЧЕБОКСАРЫ_144")
if success:
    print("ПВЗ успешно установлен")
else:
    print("Не удалось установить ПВЗ")
```

## Алгоритм работы
1. Получает селекторы для ПВЗ из конфигурации
2. Закрывает оверлей, если он мешает открыть список
3. Перебирает комбинации `dropdown_candidates` × `option_candidates` и вызывает `set_element_value()` до первого успеха
4. Ждет немного времени для применения изменений и повторно проверяет оверлей
5. Возвращает результат операции

## Особенности
- **Порядок `option_candidates` важен**: каждая неудачная попытка кликает по полю выбора и может закрыть список,
  поэтому следующая попытка ищет опции в закрытом списке и тоже не находит их. Первым должен идти селектор,
  соответствующий актуальной разметке.
- Селекторы не содержат хэш-суффиксы классов Ozon UI (`__mpRrQ`, `__TA_HC`, ...): они меняются при каждой пересборке фронтенда.
- Возвращает False в случае ошибки или если селекторы не найдены
- Если после установки `get_current_pvz()` возвращает прежний ПВЗ, а следующая навигация ведет на `/login`,
  сессия Ozon была отозвана (см. DEBUG_GUIDE, «Одноразовый токен обновления»)
- Является частью логики проверки и установки правильного ПВЗ
