# Метод `_click_close_button()`

## Версия
**0.0.3**

## Описание
Метод `_click_close_button()` выполняет клик по кнопке закрытия оверлея (модального окна). Метод **не ждет** появления кнопки: он вызывается, когда оверлей уже обнаружен, поэтому кнопка либо есть на странице сейчас, либо ее нет.

## Сигнатура
```python
def _click_close_button(self, selector: str) -> bool
```

## Параметры
- **selector** (`str`): XPath или CSS селектор для поиска кнопки закрытия

## Возвращаемое значение
- `True` — если клик успешно выполнен
- `False` — если не удалось найти кнопку или выполнить клик

## Алгоритм работы

1. **Поиск без ожидания**: `_find_elements_now(selector)` (implicit wait временно 0), берется первый видимый и активный элемент
2. **Выполнение клика**: Вызывает `.click()`; если клик перехвачен (анимация, фон) — клик через JavaScript по тому же элементу
3. **Задержка**: Делает паузу 0.5 секунды для завершения анимации закрытия
4. **Возврат результата**:
   - `True` — клик выполнен успешно
   - `False` — видимой кнопки по селектору нет

## Логирование

Метод ведёт логирование:
- `TRACE` — вход в метод с селектором
- `DEBUG` — поиск кнопки, обнаружение кликабельного элемента
- `INFO` — успешный клик по кнопке
- `WARNING` — ошибка при клике

## Пример использования

```python
# Клик по кнопке закрытия оверлея
close_button_selector = "//button[contains(@class, 'ozi__dialog__closeIcon__')]"  # без хэша класса
if self._click_close_button(close_button_selector):
    if self.logger:
        self.logger.info("Оверлей закрыт")
else:
    if self.logger:
        self.logger.warning("Не удалось закрыть оверлей")
```
