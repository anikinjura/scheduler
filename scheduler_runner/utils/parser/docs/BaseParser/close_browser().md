# Метод `close_browser()`

## Версия
**0.0.2**

## Описание
Метод `close_browser()` закрывает браузер и освобождает связанные с ним ресурсы. Метод устанавливает атрибут driver в None после закрытия браузера.

В режиме профиля `snapshot` после закрытия браузера метод:
1. если браузер парсера работал (driver был создан) — возвращает обновленную сессию Ozon из копии в профиль
   пользователя (`_sync_edge_snapshot_back()`);
2. удаляет копию профиля (`_remove_edge_profile_snapshot()`), в том числе после неудачного старта браузера.

## Сигнатура
```python
def close_browser(self)
```

## Особенности
- Закрывает браузер с помощью метода quit(); при этом Edge сохраняет cookies копии на диск
- Устанавливает атрибут driver в None для освобождения ресурсов
- Проверяет, что драйвер существует перед попыткой закрытия
- Обратная запись сессии пропускается (`EDGE_SNAPSHOT_SYNC_SKIPPED`), если Edge пользователя запущен
  или его cookies изменились за время работы парсера: сотрудник уже работает со своей сессией
- Является частью основного цикла работы парсера
- Обычно вызывается в блоке finally для гарантированного закрытия браузера и удаления копии профиля

## Связанные методы
- `_sync_edge_snapshot_back()` - копирует `EDGE_SNAPSHOT_SYNC_BACK` (Cookies, Local Storage, Session Storage, IndexedDB)
  из копии в профиль; каталоги заменяются через временную копию, устаревший `Cookies-journal` удаляется.
- `_remove_edge_profile_snapshot(snapshot_user_data_dir)` - удаляет копию профиля с повторными попытками.
